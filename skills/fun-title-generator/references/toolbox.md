# 错位工具箱

生成标题时不要想"我该用哪个工具"。先想：**这个场景里哪个默认预期最容易被攻击？** 找到后，下面所有工具都是帮你把攻击变成标题的手段。

---

## 一、四个攻击方向

| 攻击方向 | 攻击的是… | 翻转口诀 | 示例 |
|----------|----------|---------|------|
| **规模错位** | 事情本应的大小 | 把芝麻讲成西瓜 | "冰箱门一关，就是永别" |
| **身份错位** | 谁/什么东西扮演什么角色 | X 其实不是 X，X 是 Y | "我的嘴还没打卡" |
| **逻辑错位**（因果） | "我做这件事"的因果链 | 不是我想 X，是 Y 让我不得不 | "被窝不让我走" |
| **语气错位** | 什么事该用什么语气说 | 用另一个世界的语言讲这件事 | "今日完成工位摸鱼全流程闭环" |

> 四个方向不互斥。好标题往往同时攻击两三个方向。

---

## 二、三种语言纹理

同一个攻击方向，用不同纹理写出来，触感完全不同：

### 口语纹理
像一个人脱口而出的话。短、滑、有自然顿挫。如"被窝不让我走"（逻辑错位 → 5 个字）。

### 格式纹理
像网上捡来的句子，读者第一反应是"我也要套一个"。如"从 xxx 到 xxx，中间隔着一个 yyy"。

### 腔调纹理
用机构语言把日常行为重新上色。运维腔 / 医学腔 / 战报腔。风险：容易掉进"像论文但不好笑"的坑。判断标准：腔调是一层膜，揭掉之后底下的场景本身仍然好笑。撤了腔调就什么都没了 = 硬焊。

## 三、13 框架速查 + 填空公式

| 框架 | 适合场景 | 填空公式 | 示例 |
|------|---------|---------|------|
| 纪录片 | 任何日常行为 | 人类早期 + 动作升级 + 被重新定义的物体 + 珍贵影像 | 人类早期驯服家中野生零食的珍贵影像 |
| 刑侦通报 | 找/抓/拿/控制 | 关于 + 某物 + 擅自行为 + 的情况说明 | 关于部分零食擅自离开桌面的情况说明 |
| 动物世界 | 人的本能行为 | 一群 + 物种化的人 + 对 + 物种化的物体 + 展开行为 | 一群成年幼崽正在围猎桌面薯片 |
| 科研论文 | 生理/本能反应 | 研究发现 + 人类在某条件下 + 出现异常反应 | 人类双手对零食产生不可逆吸附反应 |
| 职场汇报 | 幼稚行为装工作 | 完成 + 某某治理/闭环/回收/管控 | 今日完成零食回收闭环 |
| 官方通报 | 混乱/失控场景 | 关于 + 某物 + 擅自/失控行为 + 通报 | 关于部分零食擅自离开桌面的情况说明 |
| 灾难新闻 | 散落/外溢 | 某地发生 + 某物失控/外溢/逃逸 | 六一现场出现小规模碳水外溢事件 |
| 战争史诗 | 抢/争夺 | 某战役 + 取得阶段性胜利/全线崩溃 | 睡眠计划在第一条短视频面前宣布无条件投降 |
| 考古发现 | 当下→未来遗迹 | 发现 + 早期人类 + 某行为遗址 | 发现早期人类围猎零食遗址 |
| 医学诊断 | 馋/懒/困等本能 | 确诊：某物 + 依赖性 + 某综合征 | 确诊：糖分依赖性桌面吸附综合征 |
| 神话传说 | 节日/玄学 | 某物显灵/降临 + 某物自动归位 | 六一显灵，零食自动归位 |
| 法律文书 | 甩锅/责任划分 | 关于 + 某事件 + 的责任认定 | 关于本次赖床事件的责任认定 |
| 赛事解说 | 竞赛/比较 | 本届 + 某行为大赛 + 冠军诞生 | 本届沙发瘫大赛冠军诞生 |

> 公式只是骨架——套出来像论文、像硬焊就丢掉，回到口语重写。

## 四、身份替换 + 动作升级

这些是手法参考，换了场景就重新生成：

### 物体 → 另一个身份
零食→野生动物 / 手机→注意力诱导装置 / 被窝→非法拘禁设施

### 人 → 另一个角色
同事→协同伪装者 / 自己→涉事主体 / 老板→巡查力量

### 地点 → 另一个场所
办公室→高风险区 / 群聊→静默区域 / 健身房→年费回收站

### 常用替换速查

| 原物 | → | 原动作 | → |
|------|---|--------|---|
| 零食 | 野生零食、在逃糖分、失控碳水 | 拿 | 缉拿、收容、捕获、驯服 |
| 人 | 早期人类、研究员、馋虫宿主 | 吃 | 消灭、无害化处置 |
| 桌子 | 收容中心、案发现场、栖息地 | 抢 | 围猎、资源调配 |
| 房间 | 生态系统、考古遗址 | 放回去 | 劝返、归案 |

## 五、4 算子推导（框架表不够用时）

### 算子表

| 算子 | 核心操作 | 自检问题 | 对应攻击方向 |
|------|---------|---------|------------|
| **史诗化** | 把微小事件升级为宏大叙事 | 我把一个普通动作讲成了什么文明里程碑？ | 规模错位 |
| **角色错位** | 颠覆主体或客体的固有身份 | 谁/什么东西被换成了完全不像的身份？ | 身份错位 |
| **因果倒置** | 重新分配责任与逻辑 | 我把"我想做"翻转成了"什么东西在作怪"？ | 逻辑错位 |
| **机械解体** | 把流畅行为拆解为僵硬步骤 | 我把本能反应讲成了需要多少步骤的复杂流程？ | 语气错位 |

### 公式
```
选算子 → 找到被攻击的预期 → 翻转它 → 为新设定找叙事框架 → 生成标题
```

### 示例 1：因果倒置（挤地铁）

```
场景：周一早上挤地铁，大家都面无表情

翻转因果：不是我要上班，是地铁把人吸进去的
找外壳：地铁有意志 → 神话 / 工位是诱捕器 → 动物世界

生成：地铁口捕获大量周一迁徙打工人
```

### 示例 2：机械解体（奶茶走不动道）

```
场景：看到奶茶走不动道

拆解：眼球锁定 → 大脑异常信号 → 双腿自主改变航向 → 手部支付
找外壳：实验室报告 → 科研 / 系统日志 → 运维

生成：系统日志：检测到用户双腿执行非授权转向操作
```

### 翻转箭头对照

| 算子 | 原方向 | 翻转后 |
|------|-------|--------|
| 史诗化 | 小事是小规模 | 小事是文明级别的 |
| 角色错位 | X 就是 X | X 其实是 Y |
| 因果倒置 | 我想做 → 我做 | 它让我做 → 我不得不做 |
| 机械解体 | 本能是流畅的 | 本能是需要步骤一二三的 |

## 六、使用决策

```
场景元素清晰，框架表有匹配 → 直接用 13 框架
框架表没匹配的 → 选 1 个算子推演
框架生成的标题不够好笑 → 改用算子
用户要更意外的 → 优先用算子
```

## 七、筛选维度

### 通用维度（路径 A / B 都适用）

| 维度 | 自检问题 |
|------|---------|
| **场景焦点** | 标题对的是用户描述的场景，还是我脑补的情节？ |
| **共鸣颗粒度** | 同时命中场景里多个信息点，还是只打中一个？ |
| **口语肌理** | 像不像一个真人的脱口而出？有没有书面感/翻译感？ |
| **格式繁殖力** | 读者第一反应是不是"我想套着用"？ |
| **1 秒可懂** | 不需要停下来想"这是什么意思"？ |
| **不解释笑点** | 有没有把梗说破？ |
| **画面感** | 读完脑子里是否立刻有画面？ |
| **绝对感** | 有没有"永远/无条件/不可逆/全部/彻底/任何"这类把事说死的词？ |

### 错位路径专属维度

| 维度 | 自检问题 |
|------|---------|
| **错位强度** | 小事有没有被完整放进一个完全不属于它的严肃系统？ |
| **类比自然度** | 框架和场景的映射是"发现"出来的还是"硬塞"的？ |
| **腔调完整性** | 框架词汇从头贯穿到尾，还是半截子掉回口语？ |
| **具体名词对撞** | 标题里有没有两个泾渭分明的具体事物在碰撞？ |

### 排序方式

**不打数字分。** 强制找至少一个真实弱点。三档：

| 档位 | 处理 |
|------|------|
| **明显更好** | 进 TOP 5 |
| **中等** | 备用 |
| **偏弱** | 淘汰 |

## 八、直接淘汰规则

| # | 类型 | 典型症状 | 示例 |
|---|------|---------|------|
| 1 | **解释型** | 把梗说破 | "我们像特工一样假装在工作，真的很好笑" |
| 2 | **空形容型** | 只有氛围没画面 | "周五摸鱼大狂欢" |
| 3 | **堆词型** | 像论文但不好笑 | "工位生态系统中的注意力分配重构" |
| 4 | **半错位型** | 前半句在框架，后半句自我解释 | "闹钟像有生命一样攻击我，我们像战士一样对抗它" |
| 5 | **框架破碎型** | 只剩术语词，腔调不完整 | "被窝非法拘禁" |
| 6 | **硬焊型** | 概念强行焊在一起 | "关于一整套妆容未能遇见任何目击者的侦办通报" |
| 7 | **过拟合型** | 在讲用户没说的情节 | 用户说"冰箱被清空"，标题说"刚补的货就被消灭了" |

### 最终测试

**如果把这个标题发给一个完全不知道原场景的人，他会不会觉得好笑？** 犹豫就换。

## 读法

- `A` = 错位路径：把日常动作放进不属于它的严肃系统。
- `B` = 精准观察路径：不套框架，只说出人人经历过但没人说穿的事。
- 候选 ID 必须能在同一案例里回查；不要写脱离候选池的 `A4/B1` 评价。
- 用户选择不是绝对答案，而是排序校准信号。

## 核心正例

这 5 个优先作为教学案例。被反馈"不知道在说什么"的短标题不放在开头正例里。

### 1. 地铁刷手机坐过站

- 场景：低头刷短视频 → 没听报站 → 抬头发现已经过了三站。
- 候选：A1 不是我想坐过站，是手机不让我抬头；A2 人类被短视频捕获，错过自然迁徙节点；A3 本趟列车擅自越过目标站台，乘客全程未察觉；A4 确诊：短视频诱发性方位脱轨综合征；A5 地铁已过三站，眼睛仍坚守在屏幕前线；B1 刷手机的人，到站永远比别人多一站；B2 坐过站的标准公式：看了一条，又看了一条；B3 在你最投入的那条视频里，地铁替你做了决定。
- 用户选择：**B1 刷手机的人，到站永远比别人多一站**。
- 校准：用户要社会比较 + "永远"绝对感；不要文艺腔或战争腔。

### 2. 熬夜刷视频

- 场景：说再看一条就睡 → 手指一直上滑 → 刷到凌晨两点。
- 候选：A1 从十一点到两点，中间隔着一个再看一条；A2 今晚的我是明天最恨的人；A3 系统日志：用户已连续 127 次执行"最后一条"协议；A4 患者自述：手指在无意识状态下完成 3 小时滑动操作；A5 睡眠计划在第一条短视频面前宣布无条件投降；B1 "再看一条"是成年人对自己说的第二大谎；B2 早睡的誓言，天亮前都会被算法击穿。
- 用户选择：**A5 睡眠计划在第一条短视频面前宣布无条件投降**。
- 校准：完整战争腔成立；"无条件投降"这种绝对化措辞比格式句更有戏剧性。

### 3. 想拿水果，结果拿了冰淇淋

- 场景：走到冰箱前想健康一下 → 开门后手伸向冰淇淋 → 水果被无视。
- 候选：A1 不是我想吃冰淇淋，是冰箱门开的瞬间它自己跳出来的；A2 研究发现：人类手掌对冰淇淋包装产生不可逆吸附反应；A3 关于水果被冰淇淋截胡的现场调查报告；A4 冰箱里的水果，是人类最熟悉的陌生人；A5 水果在冰箱里见证了一场自己从未赢过的比赛；B1 打开冰箱前你是健康人，关上冰箱后你是罪人；B2 冰淇淋和水果之间，差的不是距离，是意志力。
- 用户选择：**A2 研究发现：人类手掌对冰淇淋包装产生不可逆吸附反应**。
- 校准：科研腔要落到具体身体动作；"不可逆/吸附"比隐喻式情感文案更有力。

### 4. 视频会议没关麦偷吃东西

- 场景：以为自己 muted → 开始吃薯片 → 同事问"谁在吃东西"。
- 候选：A1 薯片在静音状态下，仍然被全公司声呐系统捕获；A2 我以为我 muted 了，但薯片没有；A3 关于某员工在线上会议中擅自咀嚼的调查报告；A4 患者自述：静音键按下后出现进食冲动，全程未被有效屏蔽；A5 线上会议：一场以为自己 muted 但其实没有的全球性幻觉；B1 每声咔嚓都在证明：你永远不知道你的麦到底关了没；B2 听到"谁在吃东西"的那一刻，嘴里的薯片不敢嚼了。
- 用户选择：**A2、A1、A3、A4**。
- 校准：A2 最短且自解释；技术词如"声呐系统"必须精准服务声音画面；通报腔适合社死现场。

### 5. 手机掉地上第一反应用脚垫

- 场景：手机滑落 → 脚本能去垫 → 踢得更远 → 屏幕朝下落地。
- 候选：A1 我的脚在手机坠落瞬间做出了一个让情况更糟的反应；A2 脚：我以为我在救它，但我只是在给它加了个旋转；A3 研究发现：人类在手机坠落时会触发无意义脚部拦截反射；A4 手机坠落 0.3 秒内，脚部完成了从救援到助攻的转变；A5 关于手机被脚二次击飞的技术分析报告；B1 脚垫那一下不是救手机，是给落地加了个弧线；B2 手机掉地上之前，你的脚一定会帮它飞得更远。
- 用户选择：**A5、B1、A3、A4**。
- 校准：最具体的动作转折是"二次击飞/加弧线"；科研腔点睛词是"无意义"。

## 偏差记录

| 场景 | 模型原偏好 | 用户偏好 | 校准 |
|------|------------|----------|------|
| 地铁过站 | 地铁已过三站，眼睛仍坚守在屏幕前线 | 刷手机的人，到站永远比别人多一站 | 社会比较 + 绝对感 > 文艺腔 |
| 熬夜刷视频 | 从十一点到两点，中间隔着一个再看一条 | 睡眠计划在第一条短视频面前宣布无条件投降 | 完整腔调 + 戏剧性 > 格式繁殖力 |

## 偏好案例库

以下用于校准排序，不必每次生成都完整读取。

### 1. 健身房办了卡从没去过

- 场景链：交钱时激情澎湃 → 卡塞钱包里 → 路过健身房假装没看见 → 月底扣款心疼三秒。
- 候选：A1 健身卡在钱包里，已经不认识健身房了；A2 我与健身房的距离：隔着一张永远刷不出去的卡；A3 健身房年费：我人生回报率最高的慈善捐赠；A4 患者自述：身体对跑步机产生本能性回避反射；A5 健身卡已完成全年休眠任务，打卡记录零；B1 买了卡就等于练了，只是身体还没收到通知；B2 健身房里最熟悉的陌生人，是我那张卡。
- 用户选择：A3（消费→慈善捐赠，自嘲尖锐）；A1（卡拟人，1 秒懂）；A2（"永远刷不出去"绝对化）。
- 淘汰信号：A4/A5 腔调重但笑点慢；B1/B2 金句感强，不够自然。

### 2. 把购物车当收藏夹用

- 场景链：刷到好东西 → 加购物车冷静 → 一个月后还在 → 再看已下架。
- 候选：A1 我的购物车是个黑洞，放进去的东西再也见不到光；A2 加入购物车的那一刻，这个东西的使命就已经完成了；A3 商品在购物车里等了 47 天，最终等来了"已下架"；A4 研究发现：人类存在"加购即拥有"幻觉；A5 购物车里的东西和我的缘分，止于结算按钮前一毫米；B1 放购物车冷静的结果，就是看着它变成灰色已下架；B2 收藏夹是给喜欢的，购物车是给买不起的喜欢的。
- 用户选择：A4（"加购即拥有"精准，"幻觉"专业但不绕）。
- 淘汰信号：场景共鸣门槛较高；B2 信息压缩过猛，1 秒内不够顺。

### 3. 收到消息秒读但不回复

- 场景链：消息来了 → 脑子里回复完 → 手指没动 → 三天后对方发"？"。
- 候选：A1 我的大脑回复了，但手指那边还没收到通知；A2 消息已读未回：人类社交领域的最大未解之谜；A3 关于三条消息被意念回复后石沉大海的情况说明；A4 患者自述：脑内回复功能正常，指尖传输通道持续断开；A5 聊天记录显示：对方的消息在我脑子里活了三秒；B1 已读不回，是当代人对自己说"等会儿回"的遗体；B2 对方发"？"的那一刻，我就知道意念回复又败露了。
- 用户选择：A2（宏大化 + 最大未解之谜）；A1（大脑/手指分部门）；A4（故障点落在指尖）。
- 淘汰信号：A3/A5 稍绕；B1 词太重；B2 更像正文吐槽。

### 4. 取快递时忘记取件码

- 场景链：信心满满到快递柜 → 取件码被短信顶到三天前 → 站着翻五分钟。
- 候选：A1 取件码在短信列表里，进行了一场为期三天的逃亡；A2 人类站在快递柜前的平均翻短信时长：三到五分钟；A3 我与我的快递之间，隔着一个永远找不到的六位数；A4 取件码在 47 条验证码短信中完成了隐身；A5 每次取快递，都是一次对手机短信搜索功能的突击测验；B1 快递到了三天，取件码也失踪了三天；B2 快递柜前的我，永远在重复同一个动作：往上滑往上滑往上滑。
- 用户选择：A3（六位数具体，永远绝对，距离感一秒成画）。
- 淘汰信号：动作单一，容易复述问题；A1/A4 没有 A3 直观。

### 5. 洗完澡躺床上突然想上厕所

- 场景链：洗完澡钻进被窝 → 五分钟后膀胱发信号 → 被窝和厕所之间天人交战。
- 候选：A1 被窝与厕所：一场发生在凌晨的领土争端；A2 身体在被窝里很暖，但有一个器官在策划叛变；A3 患者自述：入睡后 5 分钟出现不可逆膀胱唤醒现象；A4 睡前上厕所，是成年人对自己最后的善意；A5 被窝不让我去厕所，厕所不让我睡觉；B1 世界上最远的距离，是被窝到厕所的那段路；B2 洗完澡躺下的那一刻，膀胱才开始认真工作。
- 用户选择：A3（不可逆 + 医学腔）；A5（双主体甩锅）；B1（经典句式贴合痛点）；B2（生理时机拟人）。
- 淘汰信号：A1 框架离身体感远；A2 略用力；A4 像生活建议。

### 6. 出门后反复确认门锁了没

- 场景链：锁门 → 走三步回头拉门 → 进电梯又怀疑 → 折返回去再拉。
- 候选：A1 门锁确认仪式：一种当代人类普遍执行的无效行为；A2 我的手锁了门，但我的大脑不信任我的手；A3 每天出门，都要和门把手进行三次以上告别握手；A4 确诊：出门后门锁存在性怀疑综合征；A5 本次出门共计折返两次，拉门三次，确认门锁状态无误；B1 门已经锁了，但你的大脑还没收到确认函；B2 走了三步就回头，是成年人对自己记忆力的诚实评估。
- 用户选择：B1（"确认函"把心理不确定性变成行政流程）。
- 淘汰信号：一个准名词胜过整套大框架；A1/A4/A5 太像诊断说明。

### 7. 周末设了闹钟结果自然醒

- 场景链：周五设 8 点闹钟 → 周末想早起 → 自然醒 7:58 → 闹钟白设。
- 候选：A1 闹钟：我为了今天准备了整整一周，结果你提前两分钟醒了；A2 自然醒在 7:58 对人类发起的精准打击事件；A3 研究发现：周末闹钟前 2 分钟是人类睡眠效率最高的时段；A4 闹钟的职业生涯，在 7:58 那一刻宣布终结；A5 周末闹钟永远在你自然醒的前一秒，完成一生的使命；B1 周末闹钟存在的意义，就是被你提前两分钟关掉；B2 7:58 醒来，是全人类最亏的两分钟。
- 用户反馈：整体"完全看不懂是什么"，作为失败校准。
- 失败信号：笑点压在 7:58 和 8:00 的时间差上，没有上下文时读者无法自解。

### 9. 网购衣服不合身但不退货

- 场景链：试穿不合身 → 对自己说瘦了再穿 → 衣柜放一年标签还在。
- 候选：A1 这件衣服在衣柜里等了一年，还没等到我瘦下来；A2 不合身的衣服，是我对未来自己的长期投资；A3 衣柜深处：一个从不退货但也不穿的衣服收容所；A4 研究发现：人类存在"明天就开始减肥所以先留着"认知偏差；A5 每一件不合身的衣服，都承载着一个"明年夏天"的谎；B1 不退货的唯一理由：我相信明年夏天自己会瘦；B2 衣柜里最贵的东西，是那些挂着标签的"等我瘦了再穿"。
- 用户选择：A2（长期投资 = 自欺欺人的理性包装）。
- 淘汰信号：核心是"我骗自己"，不是"衣服在等我"。

- 淘汰信号：A1 太像普通描述；A2 没有 B1 直观；B2 略泛。

### 11. 拆快递时剪刀就在抽屉里但非要徒手撕

- 场景链：知道剪刀在哪 → 懒得走两步 → 硬用手撕胶带 → 上牙咬气泡膜 → 手指发红。
- 候选：A1 人类已进化出手撕快递的原始技能，工具被选择性遗忘；A2 剪刀在抽屉里目睹了一场手指对胶带的徒手围剿；A3 研究发现：人类取剪刀的意愿与快递期待值成反比；A4 不是我想徒手，是我的腿说抽屉太远了；A5 关于一把剪刀在拆快递行动中被全程闲置的情况说明；B1 拆快递时的手指，永远觉得自己比剪刀快；B2 你的手指有洪荒之力，只是没想到胶带也有。
- 用户选择：A5（通报腔完整，"全程闲置"精准）；A3（科研公式感强）；B1（口语精准，"永远"绝对化）。
- 20 字内推荐：关于剪刀被全程闲置的拆快递通报
- 淘汰信号：A1 概念略泛；A4 太口语，框架弱；B2 有热词感，腔调不够稳。
- 校准：工具被无视类场景，重点不是"没有工具"，而是"工具在场却被全程闲置"；长版可用于推导，最终标题必须压到 20 字内。

### 12. 闹钟响了按掉继续睡，梦见自己已起床出门
